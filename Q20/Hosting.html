Ready for the web

Publish your website.

These pages are static files. Upload the complete folder to a static web host or your college web server.

  1. Check the files

    Keep all site files together: the five HTML pages, style.css, app.js, northstar-logo.svg, and the image files (campus.jpg, Vaibhav.png, Alex Morgan.jpg, and Jordan Leee.jpg). Update sample college text, staff placeholders, and contact details before publishing.

  2. Choose a web host

    Use a static hosting service or obtain access to your college web server. For a traditional host, ask the administrator for the server address, upload method (often SFTP or a hosting control panel), and the correct public web directory (often named public_html or www).

  3. Upload the site

    Connect using the host’s dashboard or SFTP client. Upload every file into the site’s public directory, preserving the filenames and keeping the images beside the HTML pages, style.css, and app.js. Do not upload only the landing page.

  4. Open it in a browser

    Visit the URL supplied by your host, such as https://your-domain.example/CollegeWebsite.html. If your host requires index.html as the default page, rename CollegeWebsite.html to index.html and update the navbar links that point to it.

  5. Test the published pages

    Open each page, follow every navigation link, resize to a phone-sized screen, and check that the stylesheet, JavaScript, and Bootstrap CDN assets load. Confirm the host serves the site over HTTPS.

Before going live

  • Use the required file names and matching letter case.
  • Replace fictional/sample content, team placeholders, and sample portraits with approved content.
  • The contact form is a front-end demo only; connect it to a trusted server-side form service to receive messages.
  • Bootstrap is loaded from a CDN, so visitors need an internet connection for Bootstrap styling and the mobile menu.
